👋 Hello! I am a Computer Science Student & Developer

Welcome to my Contact Book & Address Manager! I designed and developed this application from the ground up to gain practical experience with full-stack web development, database architecture in MySQL, and algorithmic problem-solving in Python.

💡 Project Engineering Focus

Instead of relying on heavy abstractions or bulky frameworks, my goal was to master the core fundamentals of web engineering:

  • Pure Backend Architecture: Clean multi-page routing and HTTP form processing natively built with Python Flask.
  • Database Security & Normalization: Direct MySQL relational storage using strict parameterized queries (%s) to prevent SQL Injection.
  • DSA Concept (Dictionary / Hashing): Demonstrating how an in-memory Hash Table (Python Dictionary) achieves instantaneous $O(1)$ search lookups in contrast to $O(N)$ linear list searches.

🧱 Core Engineering Principles Practiced

🧩 Modularity & Separation of Concerns

Separated database persistence (database.py), routing & business logic (app.py), and algorithmic lookup (dsa/contact_hash.py) into clean, testable layers.

🛡️ Security-First Database Access

Enforced parameterized queries across all CRUD operations to systematically eliminate SQL injection risks without requiring a heavyweight ORM.

⚡ Algorithmic Efficiency (Hashing)

Demonstrated average O(1) constant-time key lookup using Python's internal dictionary hashing mechanism to contrast against O(N) linear array scans.

🎯 Defensive UX & Validation

Implemented dual validation on frontend and backend, with duplicate phone prevention and non-destructive form re-population on input errors.
